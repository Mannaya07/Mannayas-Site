In this tutorial, I will guide you on how to type every key in CAPS on an Eng/Ita keyboard.


So let's start with the various methods we have to type keys in CAPS. Hope it will help you :>




So, in order to start typing keys in CAPS, we obviously need a keyboard. After that, we can start with the first method:

1. For the first method to type a key in CAPS, you can hold Shift and then press a key on the keyboard. This will work with most keys. There are some keys that cannot be CAPSED, and we will see later in the tutorial how to do that with those keys too.

2. The second method is to press CAPS Lock, which is the big button labeled "CAPS" on your keyboard, usually near the "A". This will make every key you type appear in CAPS, and if you hold Shift while having it enabled, the word will be in lowercase. But even with this method, there are some keys that you can't type in CAPS, and now we're going to see how to do them.





So, to make these keys in CAPS, it's actually a little bit harder. If you need to read this again, feel free to do it. It can be normal not to get it at first.

So, on your PC, if you have a numeric pad, for doing these special CAPS keys, you need to first activate it. Usually, there is a light that indicates whether it's activated or not. If the light is off, click "Num Lock". If it's not, it's already active and you can do these special key combinations. If your keyboard has no light that indicates whether it's active or not, try the combination, and if it doesn't work, click "Num Lock" and try again.

IF I DON'T HAVE A NUMERIC PAD, HOW DO I DO IT?

If you don't have a Numeric Pad, you can use the Emoji Panel or the Character Map to find the letter that you want.

1. To open the Emoji Panel, you have to do: ( hold the Windows Button and click . ) | Or (hold the Windows Button and click ; ).

2. To open the Character Map, you have to do: ( hold the Windows Button and click R ) and then write "charmap" and click Enter.
